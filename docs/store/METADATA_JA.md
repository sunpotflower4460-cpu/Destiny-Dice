# App Store メタデータ（日本語）

## 名前
Intention Dice

## サブタイトル
1年間のパーソナル実験・記録

## プロモーション文
毎日の小さな実践、気分、ランダム抽選、願いの経過を、1年間ひとつの記録として残すパーソナル実験アプリです。

## 説明
Intention Dice は、日々の「意図する」「記録する」「結果を見る」を、1年間のパーソナル実験として続けるためのローカルファーストな記録アプリです。

毎日のセッションでは、登録時に固定した5つの実践パターンをスケジュールに沿って行い、気分のpre/post、抽選結果、予言の確信度を記録します。願いは登録直後に実践群または封印群へランダムに割り付けられ、締切時に結果を判定します。

主な機能:
- 1年間の事前登録済みセッション
- ランダムビット列と実際のRNG sourceを記録
- 気分・エネルギーのpre/post記録
- 願いのランダム割付と締切判定
- 追記専用ハッシュチェーンによる改竄検知可能な履歴
- 偶然の期待値を併記する統計ラボ
- 実験終了後にのみ生成される最終レポート
- ローカル通知と、任意の週次chain-head外部アンカー
- JSONエクスポートと同じ分析コードによるレポート再生成

このアプリは、単一の個人実験から超常現象や普遍的な因果メカニズムを証明すると主張するものではありません。結果は、事前登録した個人実験の範囲で「基準を満たした／否定的証拠／結論不十分」として表示します。

データは原則として端末内に保存されます。外部アンカーを有効にした場合でも公開されるのはchain headのハッシュ等の監査情報のみで、願い本文やセッション内容は送信しません。

## App Review Notes
- アカウント作成・ログイン・課金はありません。
- 初回に実験パラメータを登録すると、その実験では変更できません。
- 毎日のセッションは開始日以降すぐ確認できます。
- 最終confirmatory p値とFinal Reportは365日終了後のみ表示される仕様です。途中ラボではp値を表示しません。
- RNGは設定時にANUを第一候補とし、失敗・未設定時はRANDOM.ORG、最後に端末cryptoへfallbackします。画面・台帳には実際に使用したsourceを表示し、fallbackを量子乱数と表現しません。
- 外部chain-headアンカーは任意です。Worker未設定・オフラインでも全ローカル記録機能は動作します。
- gambling、賞金、金銭的リターン、診断・治療機能はありません。
