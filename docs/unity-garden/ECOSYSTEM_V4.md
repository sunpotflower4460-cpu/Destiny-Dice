# 生態系の循環 — ecology.v4 / flora.v2

新しい庭のための一つの改修。植物は居場所を変え、その居場所が住人を呼び、住人が実りと土を支える。
計算は整数と保存済みの乱数のみで行う。ここでの寿命や養分の単位は、庭のゲーム規則である。

## 適用と保存

- 新規 `RunStarted` は `ecologyPolicyVersion: ecology.v4` と `floraPolicyVersion: flora.v2` を記録し、`initialState.ecosystem` を持つ。
- `ecosystem` のない既存の庭は旧v3のまま。復帰時に新しい状態を推定・追加しない。次の来場者からv4になる。
- 旧種15種の順序と旧選種ロジックは維持。v4だけ24種のカタログと動的な陰を用いる。
- `Simulation.Resolve`、水の出入り、40tick、恵み・面・乱数・意図の先行確定は変更しない。
- 生態は自然シミュレーションの後に一度進む。`Resolved.postState.ecosystem` に土と植物の履歴を保存する。
- 偶然の選択は先に記録した `DrawEntropyCommitted.ecologyBase64` の64 bytesだけ。新しい種の選択、散布元、散布の成否、着地先に使う。
  不足を `exhausted` に記録し、散布を打ち切る。追加の乱数取得や `Random` はない。種の選種だけは旧版同様、適合候補の最大重みを決定的に使う。
- 作用は `Resolved.ecology.relations` に原因・送り元・届け先・量・種として残る。一投の文章と履歴は同じ投影で表示する。
- 旧状態は新フィールドを省略するため、旧ハッシュを維持する。読み込みで生態の再計算はしない。

## 局所環境と履歴

土のある各セルに、落ち葉・養分（それぞれ0〜100）、湿りの履歴（0〜12）、葉の覆いの履歴（0〜48）、
アブラムシ（0〜12）を保存。初期の養分は18、ほかは0。

- 湿り450‰以上で湿り履歴+1、そうでなければ-2。葉以上の元気な株があれば覆い履歴+1、なければ-2。
- `水辺` は湿り650‰以上かつ湿り履歴3以上。`岩陰`、背の高い隣株の `草木の陰`、湿り300‰以下・水捌け450以上の `乾いた草地`、
  その他の `花の草地` の順で分類する。図鑑には植えられる土の分類数を表示する。
- 陰は岩だけでなく、ヒマワリ・ジギタリス・野ばら・ミソハギ・アキノキリンソウの葉以上の元気な株が上下左右へ作る。
  株の衰弱や退場で陰も変わる。日向の花と日陰の花が、同じ庭の成熟につれて交代できる。
- 落ち葉は土の硬さを最大100やわらげる。水捌け・水分量を直接変更しない。
- 芽吹き→花盛り→実り→休息が24投ごとに巡る（96投で一周、世界の投数から決定）。好みの時期には結実時の種が1粒増える。
  時期による突然の枯死や、現実時間で放置したことへの罰はない。

## 花24種の役割

既存15種の条件と蜂・蝶の好みは `Flora.All` の最初の15項に維持。
追加する9種にも、硬さ・排水・湿り・光と訪花昆虫の好みがある。

| 新しい種 | 主な居場所と役割 |
| --- | --- |
| シロツメクサ | 日向・地表の覆い。根粒菌と周囲の土へ窒素を補う（1セルあたり2） |
| カラスノエンドウ | 日向・先駆的な草地。土をやわらげ、根粒菌と窒素を補う（同3） |
| ノコギリソウ | 乾いた日向。深い根で土をやわらげ、開いた花でハナアブも支える |
| タイム | 排水のよい乾いた日向。低い覆いと長めの開花、蜂の蜜源 |
| ハッカ | 湿りと水の残る場所。蜂の蜜源 |
| サクラソウ | 湿ったやわらかい陰。芽吹きの時期に実りやすい |
| スミレ | 木陰・地表の覆い。自家結実もでき、土を少しやわらげる |
| ミソハギ | 湿地。高い株で陰をつくり、蜂と蝶の蜜源。菌根網には入らない |
| アキノキリンソウ | 日向。実りの時期に種が増え、風で散布。開いた花でハナアブを支える |

生存戦略は `PlantStrategies` に集約し、図鑑も同じデータを読む。
高さ区分0は地表の覆い、1は草本、2は隣へ陰をつくる株。地表の覆いも住人の避難場所を成熟させる。

## 受粉 → 結実 → 散布

- 蜂・蝶は雨のやんだ時に、好みの開花株をそれぞれ最大3株訪れ、受粉履歴を+1（最大6）する。
  四系統の恵みが揃うことを蝶の必須条件にしない。生き物はその居場所から訪れる。
- ハナアブも、開いた花と近くのアブラムシが揃う場所で受粉と捕食の両方を支える。
- タンポポ、スミレ、ポピー、コスモスは自家結実もでき、開花中に受粉履歴が+1。
- 開花後3歩以上、受粉履歴2以上、衰弱していない時、一開花につき一度だけ結実する。
  通常2粒、果実を持つ野ばら・野イチゴは3粒、好みの時期ならさらに1粒。
- 小鳥は実った果実か、葉の覆いと十分な小虫のいる場所へ。果実を持つ株の種は距離2〜8へ運ぶ。
- 風は実った風散布の種（タンポポ・アキノキリンソウ）だけを、東2〜5セル・南北1セル以内へ。
  恵みが風の時、または風の強い天候の時に働く。流れの方角は既存の東風モデルに合わせる。
- それ以外は親から距離1〜2へ自然落下する。蜂・蝶は種の運搬者にしない。
- 各経路は候補親1株、適合する空き地がある時に2/3で散布。1投につき合計2粒まで。
  経路の順番は投数で回し、小鳥と風が落下に常に先取りされることを防ぐ。
- **子は親と厳密に同種**。違う土へ落ちたから別種になることはない。不適合の土や占有セルには着地しない。
  種を1粒使うたび、保存された親の種の残量から1を引く。
- 新しい種類が外から入る入口はサイコロの種。住人は、庭にすでにある植物の系譜を広げる。

## 土の循環と根

- 葉以上の元気な株は3投に1回、落ち葉を1残す（セルごとに位相をずらす）。
- きのこは湿り400〜950‰未満の陰と落ち葉3以上、ミミズは湿り300〜850‰と落ち葉2以上、
  トビムシは湿り250〜950‰未満と落ち葉2以上、カタツムリはそのうち湿り600‰以上に暮らす。
- 最大の活動セル数はきのこ3、ミミズ4、トビムシ6、カタツムリ3。1セルで順に落ち葉を2・3・2・2まで分解する。
  **落ち葉から引いた量だけ養分へ加える**。養分100を超える分は分解しない。
- シロツメクサ・カラスノエンドウの根粒菌は、葉以上の元気で条件の合う株の、自分と隣の土へ窒素を補う。
  これは新しい養分の供給源として記録する。小雨の3投区切りにも土へ養分1を外部から補給する。
- 芽以上・湿り150〜900‰・衰弱していない・菌根適性のある根が距離2以内でつながる。
  距離2の間には湿り条件の合う土が必要で、岩を越えてつながらない。
- 3株以上の根の網で、養分6以下の根に、養分12以上ある最も豊かな根から最大3を移す（最大3回）。
  **送り元から同量を引く**。調和の数値から成長や養分を無限に生成しない。
- 自然シミュレーションで成長した既存株は養分1を使う。条件が合う、種・開花以外の元気な株は養分1を使って追加成長12。
  同等以上の背丈の隣株が2つ以上あれば追加成長4に抑える。休んでいる花から再び芽が伸びる余地を残す。
- 蛍・トンボ・苔は生息環境を示す住人であり、直接の成長加算は行わない。願いが叶った精霊の助けは従来の幻想表現として分けて残す。

## 葉と小虫の食物網

- 3歩以上育った葉の覆い、湿り200〜850‰ならアブラムシが1増え、条件を失えば2減る（0〜12）。
- テントウムシはアブラムシ3以上と距離2以内の成熟した覆い（履歴6以上）。最大4箇所で4ずつ食べる。
- ハナアブは小雨以外で、アブラムシと距離2以内にデイジー・ノコギリソウ・アキノキリンソウ・キンポウゲの花がある場所へ。
  最大3箇所で2ずつ減らし、近くの花の受粉も助ける（幼虫・成虫の生活を一歩に集約）。
- クモは距離1以内の成熟した覆いと獲物が必要。最大3箇所で2ずつ減らす。
- カエルは湿りが4歩以上続く水辺と距離2以内の覆い、距離3以内の小虫が必要。最大2箇所から、近くの実在する群れを2ずつ食べる。
- 小鳥も訪れたセルのアブラムシを最大2食べる。各捕食者は先の捕食で減った**残り**を見るため、存在しない獲物を食べない。
- トンボには湿り履歴4以上かつ水面か湿り700‰以上の場所が必要。蛍には苔と持続した水辺と、晴れ以外の空が必要。
  一度の水投入だけで成熟した水辺の住人一式が現れないようにする。

## 回復・休息・世代交代

植物ごとに年齢、負担、開花期間、受粉履歴、種の残量、結実済みを保存する。

- 不適合な居場所で負担+2。養分0、小虫6以上、同等以上の隣株3つ以上はそれぞれ+1。全て解消していれば負担-3。
- 負担12で衰弱を記録し、毎投成長80を失う。条件改善で12未満に戻れば回復を記録。
- 負担24か寿命（64〜180歩、基本120）で株は退場。落ち葉12を残し、次の投から空き地になる。
- 花は6〜14歩で花を休め、成長900・葉の段階に戻って落ち葉6を残す。適した土と養分があれば再び咲ける。
  残った種はそのまま散布でき、次の開花では再び受粉・結実を迎える。
- 退場した株の履歴は保存済みの過去の投に残る。現在の個体メモリからだけ外す。ジャーナルは追記のみ。

## 見せ方と検証

- 新しい花9種には既存の形状生成器で個別の背丈・葉・花形・色を用意。
- テントウムシ・アブラムシ・クモ・カエル・カタツムリ・トビムシと落ち葉は1つのメッシュにまとめ、ハナアブは2匹まで飛ばす。
  見た目の揺れには表示用の乱数を使うが、生態の決定には一切戻さない。
- 衰弱は植物の色に反映。新しい株が同じセルへ入る時は、種別も描画更新キーに含めて前の花の姿が残らないようにする。
- 菌根は地上に線を描かず、実際に養分が届いた根にだけ淡い光を出す。
- 図鑑は環境別の土の数、土の循環、実際に出会った住人と花の役割を表示。図鑑・履歴はスクロールできる。
  常時の気配欄は6種までと残りの数にまとめる。

再実行手順は [C#検証ツール](../../tools/ecology-check/README.md)。実測結果は `PROGRESS.md` の本改修欄。
UnityエディタとWebGLでの描画・入力・音・性能確認は別途必要。
