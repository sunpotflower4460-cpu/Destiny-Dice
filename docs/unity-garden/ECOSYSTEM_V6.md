# 庭に根づく暮らし — ecology.v6

v5までの24種、種の記憶、土の循環を引き継ぎ、生き物の住み場所と次の世代を一つの改修として深める。
これは投数で進む庭のゲーム規則。個体ごとの年齢や現実の生態の全再現を扱うモデルではない。

## 保存と更新順

- 新しい庭だけ `ecologyPolicyVersion: ecology.v6` を記録し、`ecosystem.succession.community` を持つ。
  v5以前にはこのキーを追加せず、読み込み時に新規則へ移さない。
- `CommunityState` に小さな住人の集まり、定着を待つ場所、水辺の藻・小さな餌を保存する。
- 水・天候・面・自然シミュレーションは変更しない。生態の偶然も従来の保存済みbytesだけで、
  定着や成長・食事・移動に新しい乱数取得・時刻・端末依存の処理はない。
- 生態の湿り/覆い履歴を更新した後、水辺の食べものを進め、定着を判定する。
  定着した成体の範囲と数で訪問先を絞り、花蜜と捕食の実活動を行う。
  最後に幼生の食事と成長、成体の食事、住み場所の変化、産卵を解決する。

## 住み場所と定着

対象は蝶・テントウムシ・ハナアブ・トンボ・カエル。蜂などは従来の訪問者として庭の初期から働ける。

| 住人 | 定着に必要なもの | 幼い命の食べもの |
| --- | --- | --- |
| 蝶 | 元気な食草（シロツメクサ・カラスノエンドウ・スミレ・野ばら・野イチゴ）、近くの好む花 | 食草の葉 |
| テントウムシ | 育った葉と覆い、近くのアブラムシ | 近くのアブラムシ |
| ハナアブ | 育った葉、開いた形の花、近くのアブラムシ | 近くのアブラムシ。成体は花蜜 |
| トンボ | 湿りが続く水辺と覆い、水生の小さな餌 | 水生の小さな餌 |
| カエル | 湿りが続く水辺と覆い、藻、周囲の小虫または水生の餌 | オタマジャクシは藻 |

- 条件が3投続くと、庭の外から成体1が定着する。条件が途中で切れれば準備は初めから。
- 種類ごと2組まで、準備中の場所は6箇所まで。各組の成体は3、幼い命は2まで。
  待ち場所を増やし続けたり、同じ場所に同種を重ねたりしない。
- 成体は住み場所からの範囲内で活動する。テントウムシ3セル、ハナアブ5、ほか4。
  実在する成体数と従来の活動上限の、小さい方まで活動する。
- 蜂の後の蝶の経路変更も、この住み場所の範囲を守る。

## 食事と子育て

- 成体の食事は、その投の `nectar-fed` / `predation` で実際に消費された量から割り当てる。
  同じ量を別の組に二重計上しない。
- テントウムシは獲物が減った時に、近くの開いた花の実在する蜜も食べられる。
  ハナアブの成体は、アブラムシがなくても花蜜を飲める。成体による旧版の一括捕食はv6では行わない。
- トンボとカエルは、近くに実在する小虫や水生の小さな餌を消費する。
- 成体が食事をとれ、住み場所と幼生向けの食べものの条件があり、子育て中でも休息中でもない時だけ卵を2残す。
  成体が食べられることだけで、幼生の餌がない場所に産卵し続けない。
- 卵の最初の一歩とさなぎは蓄えで進む。それ以外の幼生は必要量を食べた歩だけ成長する。
  食べ足りない時が3投続くと育つ命を失い、その分は土へ還る。
- 蝶は6歩、テントウムシ・ハナアブは4歩、トンボは8歩、カエルは10歩で成体になる。
  蝶は幼虫→さなぎ、テントウムシ・ハナアブもさなぎを経る。
- 羽化/変態した数のうち成体上限に入る数だけが庭に残り、残りは外へ旅立つ。
- 幼虫の食草の消費は1体あたり成長20まで。根と葉の基礎となる成長750は残す。
  花や蕾まで食べた時には、その株の見た目と蜜も変わる。
- 成体の餌不足が6投続くか、集まりの世代時計が96投進むと、成体1が土へ還る。
  時計はそこで再開する。個体全ての厳密な年齢を意味するものではない。

## 水辺の食べもの

- 湿り履歴6以上、かつ水面か土の湿り750‰以上が続く場所を水辺として使う。
  生息には近くの育った覆いも必要。一度濡れただけで水生の住人を作らない。
- 水辺の藻（0〜12）は養分1を使って育つ。晴れで2、それ以外で1、上限を越えない。
- 水辺の小さな餌（0〜8）は、落ち葉があれば1、なければ藻を1消費して1増える。
  分解物に支えられる小さな水生動物を集約したゲーム内資源。
- オタマジャクシは藻を、ヤゴは水生の小さな餌を、幼生の数だけ消費する。
  食べた分を引き、存在しない餌を消費しない。
- 湿り450‰未満で乾くと、藻と小さな餌はそれぞれ最大2ずつ減り、土へ還る（落ち葉上限内）。
  水の出入りはこの処理で変えない。

## 居場所が変わる時

- 一時的に条件を失っても住人を即座に消さない。
- 条件を失って2投以上、子育て中でなければ近く4セル以内の合う場所へ移れる。
- 幼生や卵を別の池へ瞬間移動させない。幼い命は元の場所で条件を待つ。
- 4投続けて住み場所を失うと、成体は庭を離れ、残った幼い命は土へ還る。
- 定着、産卵、羽化/変態、旅立ち、移動、還元と食事を、それぞれ原因イベントとして保存する。

## 観察と見た目

- 「庭を観察」に、種類ごとの成体と幼生、卵/幼虫/さなぎ/オタマジャクシ/ヤゴの段階、
  餌不足と居場所の変化を表示。既存の全体/居場所フィルタに従う。
- 水辺の藻と小さな餌の現在量、食物網も読むことができる。
- 卵、幼虫、さなぎ、オタマジャクシ、ヤゴ、藻と小さな餌を、既存の地表メッシュ1つにまとめて描く。
  成長や定着、移動が起きた場所には小さな光を出す。演出からシミュレーションへの書き戻しはない。
- 観察は現在の保存状態、履歴の文章は実際の原因イベントから生成する。
- 調和の住人多様性では、同じ住人の卵・幼虫・さなぎを別種として水増ししない。

## 検証

実C#のテストでは、全5種類の成長、幼生の餌と食草、食事の二重計上防止、
定着の待ち時間、水辺の生産/消費/乾燥、移動の猶予、個体数/資源/保存量の上限を確認する。
384投×2庭を継続とJSONでの定期復帰で照合し、全状態の一致を検証する。
v3/v4/v5の既知ハッシュも固定し、旧庭が新規則へ無言で移らないようにする。

Unityの型解決・描画・入力・音・fpsは、.NETのドメインテストとは別に確認が必要。
