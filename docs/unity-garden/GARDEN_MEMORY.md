# 一株と一粒に残った出来事

庭を観察すると、最近の出来事を一件ずつ選べる。「この株の歩み」「この種の歩み」は、
選んだ出来事に関わった個体の記録を開く。一般的な生態の説明を増やす代わりに、
その庭に残った出来事の続きから、世代や関係を読めるようにする。

## 読める続き

根拠がある庭でだけ、次のような流れがつながる。

- ダイスが届けた種 → 芽 → 葉 → 蕾 → 花。
- 光を受けた株が蜜を補った → 花粉が届いた → 次の種が実った。
- 親株の種を小鳥や風が運んだ → 土に残った → 休息の頃を越えた → 同じ種から芽が育った。
- つる・地下茎から子株が根づいた → 親株が土へ還っても、子株の記録は残った。

由来と、直近の節目を最大8件表示する。蜜の補充・受粉・結実・回復・花を閉じた記録も、
実際にその株へ結べる時だけ含める。現在も残っているか、土へ還った記録があるかも分ける。
姿が消えたことだけから、枯死や種の失効を作らない。

「種の記録へ」「親株の記録へ」と「残した命へ」「芽吹いた株へ」で由来と続きの間を移る。
続きは現在も残る命を優先し、新しいものから最大8件を抜粋する。同じ親の種・子株はIDで重複を除き、
記録された総数を併記する。種を経た子株は親 → 種 → 子株の順で読む。種の記録がない時は、
保存された親子関係があれば直接親株へ移れる。存在のない記録へはリンクしない。

「出来事へ戻る」で選んでいた場面へ戻り、「この出来事の場所を見る」で文と場所を合わせる。
歩みからは最後の節目が記録された場所を示す。過去の株を現在の庭へ作り直さない。
居場所を切り替えると出来事の選択へ戻る。過去の出来事の下へ、現在の振り返りを混ぜない。

## 同じ場所と、同じ命を分ける

`GardenMoment.MemoryKey` は表示用の `p:<plantId>` / `s:<seedId>`。保存形式へは追加しない。
`GardenMemories.Project` は対象runの `RunStarted.initialState` と解決済みの `Resolved.postState`、
実際のイベントを読み、`PlantId`・`SeedId`・`PlantAncestry`・`RestingSeed.ParentPlantId` で記録を結ぶ。
同じ場所・同じ種類であるだけでは親子や種の継承を推測しない。

- 成長と土への還元はイベントの株IDを使う。同じセルに別株が入っても、以前の株の死を新しい株へ付けない。
- 蜜や受粉などの関係には株IDがない。その投の終了状態にいる同種の株へ結び、
  同じセルで株が土へ還った投は、入れ替わりが曖昧になるので結び付けを省く。量0は成功にしない。
- 種が落ちた出来事からの入口は、同じ投・出生投・種類・運び手・出発セル・到着セルが一致する土の種が
  一粒だけある場合に限る。複数候補や元の記録がない場合は、種を選び直して補わない。
- 種の目覚め・根の子株からの入口には、終了状態の株と同じIDの実際の出生イベントも必要。
- 種からの子株には、保存された種IDと実在する株、その種のセルとの一致を使う。
- 初期状態からいた株、ダイスが入れた種、種の継承、つる・地下茎を分ける。
  途中からしか記録がなければ、最初に確認できた投を示し、誕生を補わない。

各節目の居場所と面は、その投の記録から読む。生まれた投のスナップショットがなければ、
現在の居場所や面で埋めない。未解決の投や他runは使わない。

## 読み取りの費用と検証

最近の出来事は従来どおり12投の抜粋。歩みを開いた時だけ、同じrunの全保存記録を走査する。
生態の再計算は行わず、表示する由来と節目の居場所に必要な状態だけを復元する。
返すのは文・ID・場所などの独立した表示データで、ジャーナルの参照をUIへ残さない。
観察を閉じた間の投擲では歩みを再走査せず、次に表示する時に更新する。

18ケースを追加し、IDの厳密な継承、同じ場所の入れ替わり、鳥・風・つる・地下茎、
休息、0量、記録の欠落、居場所の変化、抜粋と総数、run分離、読み取り前後の不変性を検証する。
実coordinatorの96投でも、最近12投から開ける27個体・45本の由来/続きリンクをJSON復帰後と照合した。
ライブと保存復帰後の出来事について、文・場所に加え歩みを開くIDも一致する。

生態・配面・保存形式は `ecology.v8` のまま。状態・台帳・抽選を変更する経路は追加しない。
Unityエディタでは、出来事の送り/戻し、居場所の切替、親・種・子株の往復、複数の続き、
詳細との往復、場所の輪郭、パネルを閉じた連続投擲と再表示、保存復帰、文字と操作の収まりを確認する。
この環境ではUnityコンパイル・描画・入力・性能を未確認として残す。
