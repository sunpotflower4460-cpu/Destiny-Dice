# 土の育ちと根の広がり — ecology.v7

先に生きた植物の働きが土に残り、次の植物の居場所につながるようにする。
24種・種の休眠・住人の世代交代に、腐植、土地との相性、つると地下茎、生態系の境目の記録を加える。
数値と投数はゲーム内の単位であり、現実の土壌や生物の速度を推定するモデルではない。

## 保存と互換性

- 新規庭は `ecologyPolicyVersion: ecology.v7 / flora.v2`。`ecosystem.habitat` を保存する。
- `Humus`、`LastHabitat`、`StableAge` は各256セル。つる・地下茎を持つ株の `RootReserves` は株ID順に保存する。
  配列・辞書とも深く複製し、JSON復帰後も同じ状態ハッシュになる。
- v3〜v6の保存にはこのキーを追加しない。読み込んだ庭は従来の規則で続き、「次の来場者」から新版になる。
  新しい関係の履歴だけに、その時の `fromHabitat / toHabitat` を保存する。
- 自然シミュレーション、水の移動、保存済みbytesから偶然を決める原則を維持する。
  腐植・根の蓄え・広がり・環境の記録に外部乱数や実時刻を使わない。

## 落ち葉から育つ土

腐植は各セル0〜100。初めは0で、実際に分解された落ち葉から生まれる。

1. ミミズは最大3、きのこ・トビムシ・カタツムリは最大2の落ち葉を分解する。
2. 2以上を分解した時は、腐植の空きがあれば最低1を腐植へ残し、残りをすぐ使える養分へ分ける。
   養分が一杯なら、その分も腐植の空きへ回せる。
3. 分解量は落ち葉の実在量と、養分・腐植の空きの合計を越えない。
   `減った落ち葉 = 増えた腐植 + 増えた養分`。両方が一杯なら落ち葉は残る。
4. 腐植1につき硬さを2下げ、効果は最大100。先駆けの株がなくなり、未分解の落ち葉が減っても土に働きが残る。
5. 湿り300〜850‰で養分の空きがある時、4投に1回、腐植1を養分1へ戻す。
   セルごとに処理の位相をずらす。乾きすぎ・過湿・養分上限の時は残り、水量は変えない。

処理は生態の最初に腐植の養分化、訪問者の活動で落ち葉の分解を行う。
分解者は養分だけでなく腐植の空きも見て訪問先を選ぶ。
`humus-formed / humus-mineralised / decomposed` には実際に移った量だけを記録する。

## 土地との相性

種類ごとの湿り・水捌け・硬さ・光の限界は維持する。限界外では相性0で、限界内の600〜1000を段階づける。

- 湿りと水捌けは許容幅の中ほどほど高く、許容の端で600になる。
- 硬さは、その種類の硬さ上限に近づくほど低くなる。
- 日陰を好む種類は、草木による陰では800を上限とし、岩陰では他の条件を使う。
- 最も合わない条件の値を、その場所の相性にする。良い条件で苦手な条件を相殺しない。

合う場所での生態による成長は4〜12。混み合う時はその3分の1（最低1）になる。
晴れの花蜜補充は相性800以上で最大2、それ未満で最大1。曇り最大1、雨0は維持する。
サイコロから来た未決定の種の種類選びにも、適合する候補の相性を重みとして加える。
親が残した種や根からの子株を別の種類へ変える処理はない。

## 種とは別の広がり方

| 植物 | 経路 | 保存する由来 |
| --- | --- | --- |
| 野イチゴ・タイム | つる | `stolon` |
| ハッカ・スミレ | 地下茎 | `rhizome` |

- 元気な葉以上の株が相性700以上の場所で育つと、根の蓄えが1増える（上限12）。
  幼い株、負担12以上、相性不足の株は2ずつ減る（下限0）。
- 広がるには成長1000以上、開花中ではないこと、負担12未満、相性700以上、蓄え6、養分2が必要。
- 上下左右の隣に、空いていて同種に相性700以上の土がある時だけ、同種の芽を作る。
  相性の良い隣を優先し、同点は保存済みの投数とセルから順を決める。
- 親は蓄え6・養分2・成長100を支払う。子株は成長250の芽として始まり、独立して食べ・育ち・弱る。
  合う空き地がない時に費用を先払いしない。
- 根からの子株は1投1株まで。種の目覚めと合計して、既存の生態による出生上限2を共有する。
  種が2株芽吹いた投では根から増やさない。
- 子株は `originKind: vegetative`、親ID、経路、誕生投数を持つ。架空の種IDやサイコロの種の由来を付けない。
  枯れた株の根の蓄えは除去する。

## 生態系の境目と続いてきた時間

既存の水辺・岩陰・草木の陰・乾いた草地・花の草地を用い、各投の最後に区画の居場所を記録する。
同じ分類が続いた時間は最大96投。初期の未記録から始まる時は、変化の出来事を作らない。
6投以上続いた居場所が別の分類に変わった時に `habitat-shifted` を残し、新しい継続時間を1から始める。
分類が変わった直後に、古い継続時間を新しい居場所の年齢として表示しない。

隣り合う異なる居場所を境目として観察する。右と下の隣だけを数え、同じ接点を二重に数えない。
居場所のフィルタでは、両側のどちらかが該当する境目を表示する。
つる・地下茎が境目を越えた時は、実際の出発側と到着側を `clonal-rooted` に保存する。
後の庭から履歴の環境を推測し直さない。

## 観察と見た目

- 「庭を観察」に腐植の量、落ち着いた区画、境目の接点、株と土地の相性を表示する。
- 根から広がる株には、回復・生長・開花・相性・蓄え・養分・隣の空き地のうち、今待っている条件を示す。
- 図鑑にはつると地下茎の特徴、各株の由来には本当の繁殖経路を表示する。
- 腐植がある土は地表の色へ反映し、根からの子株には親から隣への低い光を出す。
  演出と観察はシミュレーションを書き換えない。

## 検証

実C#で分解の収支と上限、ゆっくりした養分化、植物が去った後の硬さ、相性の限界、
子株の種類と費用、増えられない時の待機、出生上限の共有、本当の草地/陰の境目を越えた記録、
観察の非破壊性、深い複製、JSON保存復帰を検証する。

v7の384投×2庭を継続とJSON定期復帰で照合し、全状態ハッシュ、水量不変、保存量と出生数の上限を確認する。
従来のv4/v5/v6の長期テストとv3〜v6の改修前ハッシュも維持する。
Unityの型解決・描画・操作・音・fpsの確認は、この.NETテストとは別に必要。
