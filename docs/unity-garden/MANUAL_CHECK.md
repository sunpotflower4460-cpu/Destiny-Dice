# Destiny Garden 手動確認の手引き（2026-11-14）

1回の庭は48投・約20分を想定している。サイコロを振ると、出た面の恵み（水・風・光・種）が庭に届き、庭の生き物と植物が育つ。
出目の組み合わせがラッキーナンバーやゾロ目になると、祈りの星が大きくなり、つぼみが咲く・虹が出るなどの出来事が起きる。どの目の出る確率も変わらない。

## 起動のしかた

- スマホ・外出先: https://claude.ai/artifact/TzxUkzXSnGfuVaCRCet6tp （本人のアカウントで開く。横向きにすると大きく見える）
- 手元のブラウザ: Unity で `DestinyGarden.EditorTools.BuildScripts.BuildWebGL` を実行し、`unity/DestinyGarden/Builds/WebGL` を配信して開く（例 `python3 -m http.server 8765 --directory unity/DestinyGarden/Builds/WebGL`）。
- 記録はブラウザの中に保存される。同じ庭を2つのタブで同時に開かない（[Codex の検証記録](worklogs/system/final-verification-2026-11-14.md) の既知の問題）。

## 実際に通しで遊んだ記録（WebGL、1280×720、2026-11-14）

新しい庭を始めて48投。5投目に金の星の面1に祈って当たり「7 ラッキーナンバー 6＋1」→七つめの面。ゾロ目（66）でデイジーが咲き、
18投目にダブル・ラッキーナンバー。48投目に「庭のしおり」が自動で開いた（〈虹を見たタンポポと蝶の庭〉48投・雨音の家、
ラッキーナンバー8・八の虹1・幸運の株4・叶った願い9）。ブラウザのエラーは0件。

## 分かっている制限

- スマホ実機（iOS・Android・スマホの Safari）では未確認。スマホは自動で軽い絵にし、描画倍率を上げている。縦持ちでは16:9の庭が小さい（横向きの案内を出す）。
- 同じ庭を2つのタブで開くと保存が上書きされることがある（Codex が対応予定）。
- 面の願いは次の回にも残る（毎回の賭けとして消すかは手動確認で判断）。
- 合計77・三つぞろいで「つぼみがすべて咲く」は、土や水が合わず弱っているつぼみを除く。
