# タイトルの遊び方と庭への入口（2026-11-14）

- 題字の下に「ひと振りから、庭の物語がはじまる。」「サイコロで恵みを届け、瓶の庭を育てよう。」を置いた。水・風・光・種は既存の図柄と色を使い、それぞれの名前を添えた。
- えんじ色と金縁のボタンにサイコロの紋と進行方向の矢印を付けた。画面比率に合わせて位置と文字サイズを調整し、縦長では表示する大きさで文字を描画する。装飾はボタンと一緒に沈み、押せる範囲は固定した。
- 初回は「庭づくりを始める」、一投以上ある庭は「庭のつづきへ」。既存の表示用の投数から文言を選ぶ。タイトルを閉じるボタンと既存の庭への移動を引き続き使う。
