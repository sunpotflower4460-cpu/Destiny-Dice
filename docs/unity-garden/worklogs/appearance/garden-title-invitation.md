# タイトルの遊び方と庭への入口（2026-11-14）

- 題字の下に「ひと振りから、庭の物語がはじまる。」「サイコロで恵みを届け、瓶の庭を育てよう。」を置いた。水・風・光・種は既存の図柄と色を使い、それぞれの名前を添えた。
