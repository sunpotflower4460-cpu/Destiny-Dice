# 初めての一投と庭の操作（2026-11-14）

## 完了したこと

- 起動画面に「サイコロを振るたび、瓶の中の庭が育ちます」と「庭に入る」を表示する。通常画面の操作は「サイコロを振る」「願いをかける」「メニュー」。サイコロの面は一覧として表示し、願いの画面で恵みか面を選ぶ。
- メニューから観察、家、庭の記録、図鑑、届け先、設定、遊び方へ進む。記録の中から投ごとの履歴と対応端末での書き出しを使える。視点を動かしたときは「視点を戻す」、家の近景では「庭全体を見る」を表示する。
- 観察では場所を選ぶ操作を一つにまとめ、現在の出来事や株に使えるボタンを表示する。「戻る」で直前の画面へ戻り、メニューを閉じる。設定から新しい庭を始める場合は、今の庭が記録に残ることを知らせる。
- メニューや記録の表示中は投擲ボタンを隠し、入力も遮る。表示を閉じてから次の投を始められる。願いと届け先は従来のコマンドを使い、届け先は次に準備される投から反映する。
