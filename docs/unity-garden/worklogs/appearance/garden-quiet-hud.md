# Destiny Garden の通常画面を簡潔に (2026-11-14)

- PR #37、#39、#42 の順で取り込んだ main を起点に作業。#42 で入った左上の札、ラッキーナンバー、季節の願いが叶う演出を使用。
- 庭の画面から天気・投数・届け先の常設行、投ごとの補足、七つめの面の案内、右下の生き物一覧、面の帯の説明を外した。遊び方、庭を観察、図鑑、記録から詳細を読める。エラー・欠測の通知は表示する。
- 出来事の札は恵みの印と見出しを一列に並べ、場所が分かるときだけ地名を添える。幅868で左端は1600基準のx=366。右下の表示を外し、庭にいる生き物を見渡せるようにした。
- 願った面は紫の縁取り。恵みで願ったときは該当する面をすべて強調する。七つめの面を加えられるときは星付きのボタンが現れ、縁が明るくなる。動きを抑える設定では縁の明るさを固定する。
- 差分は `Presentation/GardenBootstrap.cs`、`GardenUi.cs`、`GardenUi.Moments.cs`、`GardenUi.Navigation.cs` と `Tests/EditMode/PresentationTests.cs`。生態・抽選・保存の実装は PR #42 の版を使用。通常画面の削除に伴い、`ShowHeader`、`ShowHarmony`、`ShowResidents` の接続を外した。
