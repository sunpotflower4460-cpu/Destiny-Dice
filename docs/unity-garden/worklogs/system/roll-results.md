# 一投の結果と祈りの記録（2026-11-14）

## できるようになったこと

- 一投の直後、出目と面の恵み、実際に起きたこと、選んだ願いの一致を出来事の札で読める。面の名前と色は、公開中の面の帯と揃えた。札は次の投まで残る。
- 保存済みの出来事の場所を輪で示し、短く寄って元の視点へ戻る。生き物や花の出来事がなかった投でも、実際に水・風・光が届いた土の場所が分かるときはそこへ寄る。低刺激表示では輪だけを表示する。
- 「願いをかける」から日本語で80文字まで書ける。任意の面や恵みの願いと同じ投に添えられる。言葉はその投の記録として保存し、出目の確率と星の判定は面・恵みを選んだときの既存ルールに従う。
- 「メニュー → 庭の記録 → 投ごとの記録」で、新しい順に出目、願い、出来事、成立したラッキーナンバーを読める。16投ずつ表示して古い記録もたどれる。
- 最初の数投は、次にラッキーナンバーになる面の金の星に小さな札が付く。以後は従来の金の星が残る。

## 接続と互換性

- `GardenCoordinator.CommitIntent(kind, value, prayerText)` に任意の言葉を渡す。従来の2引数も利用できる。保存が成功した時点で確定し、同じ投の再開時に復元する。
- `RollOutcome.IntentValue`、`PrayerText`、`Moment` をライブ表示に、`RoundSummary.PrayerText`、`MomentHeadline`、`LuckySumFace` を履歴と再開に使う。追加の保存項目は `IntentCommitted.prayerText` と `Resolved.momentHeadline` / `momentCellId`。従来の保存は、保存済みの出来事や出来事候補の文を表示する。
- Claude Codeの #57 が入った `feb75be` を土台に、別の作業領域で接続した。画面・カメラの変更は `GardenUi.RollRecord.cs`、`GardenBootstrap` などの表示側にまとめ、WebGLの入力は既存テンプレートから独立したプラグインを利用する。
