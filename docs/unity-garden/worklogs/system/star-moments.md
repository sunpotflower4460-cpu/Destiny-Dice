# 星の恵みが届いた株をたどる（2026-11-14）

## 完了したこと

- 正の成長を受け取った株を、投の結果と「庭を観察」の出来事からたどれるようにした。星の恵みで成長の境目を越えたときは、芽・葉・蕾・開花の文に星を添える。成長の節目がない受け取りは、一投に代表の一株を表示する。
- 星が最後に成長を加える生態系では、その投の終状態から星の成長分を引いた値と、段階のしきい値、同じ株IDの成長イベントを照合する。旧来の祈りの星の庭では、確かめられる受け取りを表示する。入れ替わったセルは星の対象から除く。
- 「この株の歩み」では、星で進んだ節目にその理由を添える。節目を伴わない小さな成長で、受粉・実り・由来の記録を押し出さない。
- 同じ投影をライブと保存の読込に使用する。成長・生態・出目の数値、保存形式、既存実験のプロトコルに反する経路を追加していない。

## 画面との接続

- `GardenMoment.Headline` に「星の恵みで、アイリスに蕾ができた。」などの実際の出来事が入る。`CellId` はその株がいたセル、`MemoryKey` は従来の `p:<株ID>`。`GardenMemory.Steps` は同じ成長イベントに「星の恵みで」を添える。
- 受け取りだけの場合、`GardenMoment.Kind` は `star-gift`。成長の節目は従来のイベント名を維持する。星の記録がない保存は、従来の出来事を表示する。既存の画面の呼び出しで利用できる。
- `Simulation.GrowthThreshold(PlantStage)` は、芽250、葉750、蕾1500、花2500の既存のしきい値を返す。自然計算と表示の判定が共通の値を使う。
