# 島の生態系と調和の調整（2026-11-14）

## 完了したこと

- 水辺に住むカエルとトンボは、育てられるだけの餌がたまってから子を残す。オタマジャクシとヤゴは、湿りが続いている隣の水辺まで餌を探せる。餌が育つ場所の数と蓄えで一度に育てる子の数を決める。成体は近くのアブラムシも食べ、水生の餌が少ないときは近くのヤゴの分を残す。
- テントウムシとハナアブの幼虫は、親が産卵場所を選ぶときと同じ範囲のアブラムシを食べられる。テントウムシの成体は小さい群れから少量を食べ、群れが増えた場所では多めに食べる。蝶とハナアブの成体は、雨が降っていないとき、花を訪れそびれても届く範囲の蜜を探して受粉を助ける。蝶の幼虫は食草に葉を残す。
- 投が終わり、祈りの星で咲いた花まで含めた庭から、調和と季節の願いの達成を判定する。同じ生き物の幼体と成体は調和では一種類として数える。光や風によるその投の出来事と、投の終わりに島にいる生き物を記録する。
- 既存の出来事の札と「庭を観察」に、隣の水辺で餌を食べた事実を短く表示する。芽吹きや開花、羽化や変態の節目が同時にあれば、これまでの出来事の優先順で表示する。

## 保存と画面との接続

- 現在版の新規の庭と、`ecology.v8` の庭で新たに準備する投に `ecology.v9` を適用する。進行中の投は準備時の版で最後まで処理する。既存のフレームは保存したまま、次の投から追記する。
- `EcologyResult.Visits` はその投の活動や演出の候補となる位置を返す。`FinalPresence` と `Resolved.ecology.presence` は投の終わりの生き物を返す。v8 以前の記録では `FinalPresence` が null になる。図鑑の出会いは、従来の活動記録に加えて終状態の生き物も拾う。
- 既存の `Ecology.Presence` は定着した成体の居場所を含める。季節の願いの途中経過を画面で計算する場合は、`GardenCoordinator.UsesConnectedHabitats` が true の庭で `Harmony.ReadIsland(state, weather, recipes)` を使うと、幼体と成体をまとめた調和を得られる。投の終わりの調和は既存の `RoundSummary.Harmony` から読める。
