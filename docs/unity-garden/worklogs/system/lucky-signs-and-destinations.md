# 幸運の理由と一投の出来事

- 一投の結果と庭の記録に、ゾロ目、三つぞろい、合計の節目、七、願いの目の根拠を表示する。33なら「前回も今回も3の目」と表示する。
- 主な出来事は、保存済みの変化を画面に反映してから該当の場所を示す。「この投の出来事」で開花、住人の変化などを一件ずつ読み、場所を再表示できる。庭の観察から前の投もたどれる。
- 「魔法の届け先」を選び、庭の土をタップすると次に準備される投からその区画を使う。金色の輪郭は指定済みの区画、水色は今回の届け先を示す。メニューの「届け先を選ぶ」でおまかせに戻せる。配面後の変更は既存どおり次の準備から反映する。
- 昆虫を小さくし、描画する飛翔個体の上限を減らした。出目の抽選、恵みの強さ、生態の個体数、保存済みの庭の判定は既存の規則に従う。

`CareTargets.CellMode` と `cell:<id>` を既存の届け先イベントに追加した。結果と見返しは保存済みのイベントから読み取り、追加の投擲や保存を行わない。

Unity 6000.3.23f1 の対象 EditMode テスト4件、.NET の対象テスト7件、既存Webの型チェック・183テスト・ビルドが成功。画面上の試遊とゲームの再ビルドは今回の確認範囲外。
